# Gestor de Tareas - API REST en Java y Spring Boot

Aplicación web Full Stack para gestionar tareas en tiempo real, desarrollada con **Java 21** y **Spring Boot** en el backend, y una interfaz limpia en **HTML5, CSS3 y JavaScript** en el frontend.

## Funcionalidades
- **Listar tareas (`GET /tareas`):** Muestra todas las tareas registradas.
- **Crear tareas (`POST /tareas`):** Añade nuevas tareas dinámicamente desde la interfaz web.
- **Eliminar tareas (`DELETE /tareas/{indice}`):** Borra tareas completadas al instante.

## Tecnologías utilizadas
- Java 21
- Spring Boot (Spring Web)
- Maven
- HTML5 y CSS3
- Git y GitHub

## Cómo ejecutar el proyecto en local
1. Clona este repositorio: `git clone https://github.com`
2. Ábrelo en IntelliJ IDEA y ejecuta `ApiGestionTareasApplication.java`.
3. Abre en tu navegador: `http://localhost:8080/`
